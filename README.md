# 🚀 NovixOS Imager

**💿 The official imaging utility for the Novix ecosystem.**

NovixOS Imager is a desktop application designed to help users prepare bootable USB installation media for the Novix operating system ecosystem. It provides a guided workflow for account authentication, OS edition selection, license agreements, and writing an OS image to a compatible USB drive.

## 🌌 Overview

Novix OS Imager is part of the broader Novix ecosystem, an operating system initiative spanning personal computing and managed environments.

The application combines a streamlined desktop interface with account and licensing integration to guide users through the installation-media preparation process.

## ✨ Features

- 🧭 **Guided Setup** — Follow a step-by-step workflow to prepare installation media.
- 🔐 **Account Integration** — Sign in to access your Novix account and eligible editions.
- 💻 **Edition Selection** — Choose from available Novix OS editions.
- 📜 **License Management** — Review and accept the applicable agreements before proceeding.
- 🔌 **USB Drive Detection** — Identify compatible USB drives and filter them by required storage capacity.
- 📥 **Image Downloads** — Retrieve authorized OS images through secure, time-limited download links.
- 🛡️ **Image Verification** — Verify written image data using SHA-256 checksums.
- 🏢 **Enterprise Support** — Request access to the enterprise-managed edition through the organization's approval process.

*Feature availability depends on the selected edition, published images, account permissions, and backend configuration.*

## 🚀 Getting Started

### 📦 Download

Visit the [Releases](../../releases) page to check for available builds.

Download the package intended for your operating system and follow the provided installation instructions.

### 🛠️ How to Use

1. 🚀 Launch Novix OS Imager.
2. 🔐 Sign in to your Novix account or create an account.
3. 💻 Select an available OS edition.
4. 📜 Review and accept the applicable agreements.
5. 🔌 Connect a compatible USB drive.
6. 🎯 Select the intended drive and confirm your selection.
7. 📥 Follow the on-screen instructions to download, write, and verify the OS image.

Some editions may require an additional approval process before they become available.

## ⚠️ Important: USB Drive Safety

**Writing an OS image will erase existing data on the selected USB drive.**

Before starting:

- 💾 Back up any files stored on the USB drive.
- 🎯 Double-check that you selected the correct device.
- 📏 Ensure the drive has sufficient storage capacity.
- 🚫 Do not disconnect the drive while imaging is in progress.

Novix OS Imager requires elevated system permissions to perform low-level disk operations. Grant these permissions only to software obtained from a trusted source.
